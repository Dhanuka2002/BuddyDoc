# BuddyDoc Backend

This folder contains a minimal Node + Express TypeScript backend scaffold for the BuddyDoc project.

Files added:
- `src/index.ts` - simple Express server
- `src/routes/health.ts` - health-check route
- `package.json`, `tsconfig.json`

Quick start (from this folder):
```powershell
cd backend
npm install
npm run dev
```
