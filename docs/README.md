# PatientPrep SL - Your Smart Consultation Companion

**Developer:** Individual University Student  
**Current Date:** Friday, June 27, 2025  
**Location:** Sri Lanka  

## Project Overview

PatientPrep SL is a mobile application designed to empower patients in Sri Lanka to have more effective and informed medical consultations. It acts as a personal digital assistant for patients before and during a doctor's visit.

## Key Features (MVP)
- ✅ **On-device data storage only** - Maximum privacy
- 📝 Symptom logging and organization
- 💊 Medication list management  
- ❓ Question builder for doctor visits
- 📋 Pre-consultation summary generator
- 🤖 Agentic AI guidance for preparation
- 📱 React Native with Expo Go

## Core Principles
1. **Privacy First:** All patient health data stays on device
2. **No Medical Advice:** Pure consultation preparation tool
3. **Sri Lankan Context:** Built for local healthcare system
4. **Regulatory Compliance:** Full PDPA compliance
5. **Solo Developer:** Lean, focused MVP approach
