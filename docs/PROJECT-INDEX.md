## 🔑 Key Project Principles

### 🔒 Privacy First
- All patient health data stored exclusively on-device
- No PHI transmission to servers
- Maximum privacy protection with minimal regulatory overhead

### 🏥 Healthcare Context
- Built specifically for Sri Lankan healthcare system
- Focuses on consultation preparation, not medical advice
- Complements existing healthcare rather than replacing it

### 👤 Solo Developer Approach  
- Lean MVP focused on core value validation
- Realistic 3-month development timeline
- Efficient technology choices for rapid development

### ⚖️ Compliance Ready
- Full PDPA compliance framework
- Comprehensive legal disclaimers
- Clear medical liability protection
