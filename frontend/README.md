# BuddyDoc Frontend

This folder contains the React Native (Expo) frontend for the PatientPrep SL mobile app.

What is included:
- basic TypeScript config (`tsconfig.json`)
- minimal `src/App.tsx` entry
- `package.json` placeholder with useful scripts

Next steps to run locally:
1. Install dependencies:
   ```powershell
   cd frontend
   npm install
   ```
2. Start the Expo dev server:
   ```powershell
   npm run start
   ```

Notes:
- This is a scaffold. Install `expo`, `react`, and `react-native` packages before running.
